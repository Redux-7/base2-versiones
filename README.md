# Base2 · versiones

Acá están los instaladores de **Base2**, el escritorio personal para Windows. El código no está acá.

- Para instalar: bajá el `Base2-Setup-X.Y.Z.exe` de la [última versión](https://github.com/Redux-7/base2-versiones/releases/latest).
- Base2 se fija solo si hay una versión nueva y avisa; instala cuando vos se lo pedís.
- Desde Ajustes → Actualizaciones podés volver a cualquier versión anterior. Tus datos no se tocan.
- Convive con Base 1: se instala en otra carpeta y usa otros datos.

Cada versión trae `versiones.json` con la huella (sha256) de cada instalador: Base2 la revisa antes de instalar.
